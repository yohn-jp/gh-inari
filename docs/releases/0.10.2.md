# gh-inari 0.10.2

## Summary

0.10.2 supersedes the never-published `0.10.0` and `0.10.1`. Both prior tags failed the `publish` workflow's Smoke test job because `scripts/smoke-test.mjs` required the canonical `inari` invocation to resolve on `PATH`, but nothing installs it globally on a clean CI runner. `0.10.2` carries the fix (#207) and is the version intended to actually reach npm.

## Fixed

- `scripts/smoke-test.mjs` now prepends the already-installed local `node_modules/.bin` directory ahead of the inherited `PATH` before invoking `gh inari --diagnose --json`, so canonical resolution succeeds without requiring a pre-existing global install. See [#205](https://github.com/yohn-jp/gh-inari/issues/205) and [#207](https://github.com/yohn-jp/gh-inari/pull/207).
- Carries forward the `0.10.1` fix: `.codex-plugin/plugin.json` and `.agents/plugins/marketplace.json` version consistency with `package.json` (see [`0.10.1.md`](0.10.1.md)).

## Behavioral changes

None. No product/source behavior changes beyond the smoke-test CI fix.

## Upgrade instructions

Existing `0.9.x` installs upgrade normally. There is no published `0.10.0` or `0.10.1` package to migrate away from.

## Breaking changes

None.

## Known limitations

Same as `0.9.0`; see [`0.9.0.md`](0.9.0.md) Known limitations.
