# gh-inari 0.13.0

## Summary

0.13.0 is the first release after the large Implementation-native governance convergence following 0.12.1. It packages the current standalone `inari` CLI, Operational Observation, bounded Issue/PR discovery, Implementation lifecycle authorities, delegated Session execution, Change lifecycle composition, and the release-certification improvements accumulated since 0.12.1.

This release is prepared on `release/0.13.0`, rebased onto the frozen `main` baseline at `1cb15145` (#709), which itself closed a release-blocking extension-contract consistency gap found during 0.13.0 final contract review.

## Highlights

- Operational Observation for governed Issue/PR runtime evidence, including PR reviews, conversation comments, inline review comments, checks, changed-file metadata, and explicit collection availability/truncation.
- Resilient Issue/PR view and bounded operational discovery.
- Implementation-native identity, authorization, scope projection, Session binding, conformance, lifecycle, and frontier authorities.
- Change lifecycle composition including governed merge and evidence-derived terminal state.
- Delegated Session / trusted GitHub App authority and managed runtime work.
- Improved self-dogfood and release-certification evidence, including preservation of native check diagnostics.
- Expanded architecture, Implementation contract, Golden Path, delegation, and semantic-governance documentation.
- Retired the `gh inari` GitHub CLI extension distribution path in favor of the npm-only `inari`/`gh-inari` executables, including the runtime contract's `extension-bootstrap` capability and compatibility diagnostics (#674, #709; see Breaking changes).

## Fixed

- Certification evidence no longer collapses native structured check failures into opaque exit-status-only diagnostics.
- Multiple authority and lifecycle gaps identified during the 0.12.x dogfood cycle have been closed or made fail-closed.
- Package and runtime certification have been strengthened to detect artifact/version drift before npm publication.

## Behavioral changes

0.13.0 is a pre-1.0 minor release and contains substantial contract evolution. Consumers of exported library subpaths, machine-readable CLI results, Change/Implementation lifecycle APIs, or agent-authority APIs should validate their integration against the packed 0.13.0 artifact before upgrading production automation.

The canonical executable remains `inari` from the `gh-inari` npm package.

## Upgrade

```bash
npm install --global gh-inari@0.13.0
inari --version --json
```

For pre-release validation from the release branch:

```bash
pnpm install --frozen-lockfile
pnpm run verify
npm pack
```

## Breaking changes

- The `gh inari` GitHub CLI extension distribution path has been retired (#674). `gh extension install yohn-jp/gh-inari`, `gh extension upgrade inari`, and `gh extension remove inari` are no longer supported. The `extension-bootstrap` capability identifier has been removed from `--require-capability`. Use the npm distribution instead:

  ```bash
  npm install --global gh-inari@0.13.0
  inari --version --json
  ```

This release otherwise intentionally permits breaking changes to internal Implementation/Change/Session lifecycle contracts under the repository's pre-1.0 versioning policy; consumers of those library subpaths should validate against the packed artifact before upgrading production automation.

## Known limitations

None known at release time.
