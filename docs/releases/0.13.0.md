# gh-inari 0.13.0

## Summary

0.13.0 is the first release after the large Implementation-native governance convergence following 0.12.1. It packages the current standalone `inari` CLI, Operational Observation, bounded Issue/PR discovery, Implementation lifecycle authorities, delegated Session execution, Change lifecycle composition, and the release-certification improvements accumulated since 0.12.1.

This release is prepared on `release/0.13.0`, rebased onto the frozen `main` baseline at `f0dd752` (#776), which reflects all release-blocking fixes and certification hardening landed after the prior candidate baseline (#725): diagnosable provider failure propagation across the Golden Path (#733), repository-scoped native Actions REST requests (#735), refreshed README product landing page and brand assets (#763), corrected GitHub Actions artifact download HTTP contract handling (#764), formatter-policy exemption for canonical provenance artifacts (#765), bounded release-verifier response sizes (#766), rejection of residual pull requests after branch-only abort recovery (#767), rejection of encoded repository-read path traversal (#768), alignment of optional Implementation dependencies (#769), repository-host verification on review rework projection (#770), preserved semantic Issue capability aliases (#771), source-SHA-bound semantic branch creation (#772), consistent Session Certificate expiry boundary (#773), canonical Golden Path recovery status on production Change CLI results (#774), Implementation Frontier contract repository/candidate identity matching (#775), and preserved semantic template types and defaults (#776).

## Highlights

- Operational Observation for governed Issue/PR runtime evidence, including PR reviews, conversation comments, inline review comments, checks, changed-file metadata, and explicit collection availability/truncation.
- Resilient Issue/PR view and bounded operational discovery.
- Implementation-native identity, authorization, scope projection, Session binding, conformance, lifecycle, and frontier authorities.
- Change lifecycle composition including governed merge and evidence-derived terminal state.
- Delegated Session / trusted GitHub App authority and managed runtime work.
- Improved self-dogfood and release-certification evidence, including preservation of native check diagnostics, packed/live certification independent of `gh` availability, and single-artifact package certification.
- Expanded architecture, Implementation contract, Golden Path, delegation, and semantic-governance documentation.
- Retired the `gh inari` GitHub CLI extension distribution path in favor of the npm-only `inari`/`gh-inari` executables, including the runtime contract's `extension-bootstrap` capability and compatibility diagnostics (#674, #709; see Breaking changes).
- Governed review rework and Implementation re-entry flow (#717), with repository-host verification on the review rework projection (#770).
- Optional `gh auth` credential fallback alongside repository-scoped Actions credentials (#714, #718), with native Actions REST requests now scoped to the repository (#735).
- `verify` now parallelizes its task graph via Wireit (#722).

## Fixed

- Certification evidence no longer collapses native structured check failures into opaque exit-status-only diagnostics.
- Multiple authority and lifecycle gaps identified during the 0.12.x dogfood cycle have been closed or made fail-closed.
- Package and runtime certification have been strengthened to detect artifact/version drift before npm publication, including single-artifact package certification (#724).
- Native Actions governance-blob reader no longer rejects legitimate wrapped base64 content from GitHub's Git Blobs API (#720).
- Provider failures now propagate diagnosably across the Golden Path instead of collapsing into opaque errors (#733).
- GitHub Actions artifact downloads now honor the actual HTTP contract (#764).
- Canonical provenance artifacts are exempt from formatter policy (#765).
- Release-verifier responses are now size-bounded (#766).
- Residual pull requests are rejected after a branch-only abort recovery (#767).
- Encoded repository-read path traversal is now rejected (#768).
- Optional Implementation dependencies are now aligned with their contract (#769).
- Semantic Issue capability aliases are preserved (#771).
- Semantic branch creation is now bound to its source SHA (#772).
- Session Certificate expiry boundary is now consistent (#773).
- Production Change CLI results now expose the canonical Golden Path recovery status (#774).
- Implementation Frontier contract now requires the repository to match the candidate identity (#775).
- Semantic template types and defaults are now preserved (#776).

## Behavioral changes

0.13.0 is a pre-1.0 minor release and contains substantial contract evolution. Consumers of exported library subpaths, machine-readable CLI results, Change/Implementation lifecycle APIs, or agent-authority APIs should validate their integration against the packed 0.13.0 artifact before upgrading production automation.

The canonical executable remains `inari` from the `gh-inari` npm package.

## Upgrade

```bash
npm install --global gh-inari@0.13.0
inari --version --json
```

For pre-release validation from the release branch:

```bash
pnpm install --frozen-lockfile
pnpm run verify
npm pack
```

## Breaking changes

- The `gh inari` GitHub CLI extension distribution path has been retired (#674). `gh extension install yohn-jp/gh-inari`, `gh extension upgrade inari`, and `gh extension remove inari` are no longer supported. The `extension-bootstrap` capability identifier has been removed from `--require-capability`. Use the npm distribution instead:

  ```bash
  npm install --global gh-inari@0.13.0
  inari --version --json
  ```

This release otherwise intentionally permits breaking changes to internal Implementation/Change/Session lifecycle contracts under the repository's pre-1.0 versioning policy; consumers of those library subpaths should validate against the packed artifact before upgrading production automation.

## Known limitations

None known at release time.
