# gh-inari 0.17.1

## Summary

0.17.1 is a Local Runtime convergence release following 0.17.0. It connects the setup, Executor, Admission, Session, repository policy, and pull-request publication paths into one continuous operator flow and adds packed certification for that flow.

## Highlights

- **Managed Executor custody**: a configured Executor can restart from its persisted Issuer custody without requiring App ID or private-key exports in each shell.
- **Canonical setup state**: `inari init`, setup/runtime console, repository trust, and Session readiness use the same Setup Application evidence.
- **Repository branch policy**: Session creation and Admission use repository-owned branch-policy and Implementation evidence rather than a fixed fallback grammar.
- **Bounded diagnostics**: Executor, Admission, and CLI preserve the stage and minimal cause of Local Runtime failures.
- **Session-bound PR publication**: ordinary Implementation PR creation is routed through the selected Local Admission Session and Executor-owned Issuer installation credential.
- **Continuous Golden Path certification**: the packed product is exercised from setup through human trust merge/recheck, fresh-shell Runtime startup, Session creation, governed operation, and initially-absent PR publication.
- **Repository-bound console reuse**: an existing setup console is not silently reused for another repository.

## Fixed

- Executor readiness no longer depends on transient shell-only Issuer configuration after managed enrollment.
- Setup provider binding, protected-ref trust, and Session readiness now converge on execution-owner evidence.
- Stale setup generations cannot adopt newer Admission readiness as evidence for an older configuration.
- Compatibility PR publication identities follow the same Local Admission route as canonical Implementation identities.
- PR `draft` and `maintainerCanModify` metadata are preserved on the Local Admission path.
- Non-Implementation PR contracts keep their direct route even when an inherited Implementation Session selector is stale or unavailable.
- Provider outages and trust/binding failures retain bounded, distinguishable diagnostics.
- Packed certification no longer relies on pre-generated Runtime profiles, trust, Sessions, or pull requests.

## Upgrade instructions

```bash
npm install -g gh-inari@0.17.1
```

Existing supported setup state is resumed through the canonical setup application. Managed Executor custody is reused after enrollment; do not reintroduce shell-only key custody as the steady-state configuration.

## Breaking changes

None intended for the supported CLI/setup path.

## Verification focus

This patch release is intended to be validated from a real installed package using the Local Runtime operator path:

```text
setup/resume
→ fresh shell
→ Runtime
→ governed Implementation branch
→ Session
→ governed operation
→ new PR publication
```
