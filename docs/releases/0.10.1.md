# gh-inari 0.10.1

## Summary

0.10.1 is a release-integrity patch. The 0.10.0 release commit bumped `package.json` but left `.codex-plugin/plugin.json` and `.agents/plugins/marketplace.json` pinned to `0.9.0`, and the tag was cut from a commit after the release commit instead of the release commit itself. `pnpm run verify`'s package suite now catches both drifts before a tag is cut; the 0.10.0 `publish` workflow run failed at the smoke-test stage for the same reason, so `gh-inari@0.10.0` was never published to npm.

## Fixed

- `.codex-plugin/plugin.json` `version` now matches `package.json` (`0.10.1`).
- `.agents/plugins/marketplace.json` plugin `source.version` now targets `^0.10.1`, matching the released package version.

## Behavioral changes

None. This release contains no source behavior changes; it only corrects release metadata consistency.

## Upgrade instructions

Existing 0.9.x installs upgrade normally. There is no published `0.10.0` package to migrate away from.

## Breaking changes

None.

## Known limitations

Same as `0.9.0`; see [`0.9.0.md`](0.9.0.md) Known limitations.
