## Known production blocker

The installed setup console has horizontal overflow at a 360 px viewport. Real Chromium measured a 360 px viewport and 369 px document width; the `.stepper` navigation extends to 367 px. The path is rendered in `apps/setup-console/src/view.ts` and styled in `apps/setup-console/styles.css`. Production code remains unchanged. The installed wizard certification continues through its independent controls and reports this condition as `PRODUCTION_BLOCKER`.

## Environment

The local run used Node 24.21.0, pnpm 11.18.0, Linux/NixOS, Chromium 154.0.8037.57, and OpenSSH client/server from the system profile. This evidence makes no Windows or hosted-runtime claim.
